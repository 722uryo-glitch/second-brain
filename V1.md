# Second Brain V1

V1 is the first complete global-intelligence baseline for the local Second Brain.

## Collection

- Global Google News country/language editions
- GDELT topic matrix
- GitHub public events and repository search
- X recent search adapter (requires `X_BEARER_TOKEN`)
- Bluesky public search
- Reddit RSS search
- Mastodon hashtag RSS across configurable instances
- arXiv, Hacker News, BBC and configurable RSS/Atom feeds
- Direct primary-source feeds for government/research/security sources

## Processing

- URL-level deduplication in SQLite
- Full-document/body fetch where possible
- Separate raw archive and human knowledge layer
- Multilingual claim normalization with local Ollama
- Source-type credibility weighting
- Independent-domain evidence counting
- Contradiction tracking
- Adaptive fact-check queue that speeds up when backlog grows
- Source health/error counters

## Human knowledge layer

Obsidian receives a curated projection, not the full raw firehose:

- V1 Intelligence Dashboard
- External Intelligence Inbox
- Verified / partially verified / disputed / unverified claims
- Memory index

## Important limitation

The X collector is installed but cannot collect X recent-search data until an official X API bearer token is configured. GitHub works anonymously but a token is recommended for higher limits.

## Start

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\update.ps1
.\setup_v1.ps1
.\run.ps1
```

Status endpoints:

- `GET /api/health`
- `GET /api/intelligence/status`
- `GET /api/intelligence/queues`
- `GET /api/intelligence/sources`
- `POST /api/collect`
- `POST /api/documents/fetch`
- `POST /api/factcheck`
- `POST /api/obsidian/export`
